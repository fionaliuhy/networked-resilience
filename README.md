# networked-resilience
code for the work "Intercity connectivity enhances human mobility resilience to extreme rainfalls in China"


Environment and Requirements
All analyses were conducted in R version 4.5.0 on a standard laptop. The computational environment is lightweight and fully reproducible.


Hardware Specifications (for reference)

Device: MacBook Pro (Apple M3 Pro chip)

Memory: 18 GB



Data Overview

Input data: City-level daily mobility matrices 

Format: CSV files

Size: Approximately 2–3 GB per year

Processing strategy: Data are processed on a per-year basis to ensure memory efficiency

Data Note: The dataset scale used in this study is fully manageable in R on a standard laptop (see Hardware Specifications below). For users working with substantially larger datasets (e.g., individual files exceeding 20 GB), we recommend transitioning to a Python-based workflow.
